# K pro 官网 Demo

这是基于 Figma 首页节点 `51:2089` 的第一版可交互静态网站。首屏使用左侧参考对应的产品场景图替代视频，保留原稿的泡泡字标、纸条卡片、场景选择、产品探索、App、FAQ 与页尾结构。

## 预览

- 当前本机预览：http://127.0.0.1:4173/
- 直接用浏览器打开 `index.html`，无需安装依赖或构建。
- 如需重新启动本机服务，在此目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，或双击 `打开预览.command`。服务仅监听本机；终端按 Ctrl+C 停止。

## 文件

- `index.html`：首页结构、静态区块与导航。
- `app.html`：对应设计稿的 App 介绍页。
- `styles.css`：字体、颜色、版式、响应式规则与减少动态效果支持。
- `content.js`：媒体配置、纸条、场景卡片、热点说明、App 文案、FAQ 和收尾文案。
- `app.js`：场景互斥展开、图片预览、热点选择、弹窗和文案绑定。
- `background.js`：全局固定背景、章节毛玻璃过渡与全页视频进度控制。
- `assets/`：下载到本地的 Figma 图片、原始 SVG 与字体。页面不依赖临时 Figma URL 或外部字体服务。
- `验收/检查结果.json`：本次实际浏览器检查记录。
- `验收/背景滚动检查.json`：固定背景、毛玻璃、响应式与交互复查记录。

## 本版交互

1. 全页共用固定的全屏背景，前景正常滚动。首屏背景清晰，进入内容区渐进模糊并覆盖半透明灰绿色；向上滚回首屏恢复清晰。当前用静态图片占位，不对图片做缩放或位移。
2. 场景缩略图点击展开，再点击收起；同一时刻最多展开一张。展开画面可打开大图，按 Escape 或关闭按钮返回。
3. 产品三个热点与右侧说明互相联动，只展示一个详情。
4. 三项 FAQ 独立展开、收起。
5. App 按钮进入独立介绍页，返回链接定位首页 App 区。
6. 所有原参考站外链已移除。社交与联系入口展示尚待发布的信息，不发送消息、不收集资料。

## 如何更换内容

常改文案集中在 `content.js`：`copy` 管理固定区块标题及说明，其他分组管理导航、纸条、场景、热点、App、FAQ 与收尾。`copy` 中换行用 `\n`。按钮内图标和基础结构仍保留在 `index.html`。颜色和字体在 `styles.css` 开头。

更换背景图片时，只需修改 `content.js` 中的 `site.heroImage`。`background.position` 和 `mobilePosition` 控制桌面、手机裁切重心。产品探索与产品卡图片位于 `index.html`，可分别指定不同图片。

视频接口已预留：把文件放到 `assets`，将 `site.heroVideo` 改为如 `assets/hero.mp4`；`videoStart`、`videoEnd` 控制片段起止秒数，`null` 表示视频结尾。全页顶部对应片段开头、页尾对应片段结尾；反向滚动回退，停止滚动保持当前帧。视频保持暂停状态，不自动播放或循环；快速滚动时保留最新目标，等待当前定位结束后更新。加载失败或系统设置减少动态效果时使用静态图。当前 `heroVideo` 留空；控制逻辑有模拟测试，真实视频的解码、定位速度与设备兼容性仍需正式素材验证。

### 调整毛玻璃

`background.sections` 按章节 ID 配置 `blur`（像素）、`opacity`（0～1）及 `tint`（六位十六进制颜色）。目前首屏为 0px，正文为 20px，页尾为 16px。保持透明度小于 1，背景才能透出；深浅灰绿色分别搭配原有白字、深色字。

`background.transition.enter: 0.9` 表示下一章节顶部到达视口高度 90% 处开始模糊过渡，`settle: 0.4` 表示到达 40% 处完成过渡。两者之间平滑插值，上下滚动使用相同规则；`enter` 应大于 `settle`。`tintBlend: 0.1` 表示灰绿色遮罩在章节交界处以视口高度 10% 的带宽渐变。遮罩使用同一固定层上的渐变，保留同屏浅色、深色章节各自的文字对比，不让整屏变色导致上一章节难以阅读。这些参数只影响背景，不影响内容布局或视频进度。

背景、背景内部的毛玻璃遮罩与前景分层；毛玻璃用 `backdrop-filter`，不对 `main` 或章节整体做模糊。背景禁止接收点击，卡片和弹窗继续保留原有交互。布局尺寸改变时重新测量章节位置，滚动更新合并到动画帧，无持续空转循环。

可运行 `node 验收/background.test.cjs` 检查渐变可逆、全页视频映射、快速反向定位、减少动态效果和失败回退逻辑。

## 本版边界

- 当前用静态图片验证全局固定背景及毛玻璃效果，不含正式视频素材。
- 场景展开用现有场景图片替代全景占位；大图预览不是 360° 查看器。
- 产品探索与产品卡使用已有产品概念图替代色块。热点用于展示交互，后续需按最终产品图校准。
- App 界面沿用设计稿占位；未编造已发布 App、下载链接、售价或销售状态。
- 这是本地 Demo，未部署到公网，没有后台、账户、支付或真实硬件控制。
